Fray - third-party material
===========================
Fray's visual style is inspired by FlareUI (Malkkav, MIT license, see FlareUI-MIT.txt). From FlareUI:
  Textures/Icon-Border.tga                (FlareUI IconBorder)

Fonts (Fonts/):
  RobotoCondensed-Regular/Bold.ttf  - Google Inc., Apache License 2.0 (Font_RobotoCondensed_Apache-2.0.txt)
  Marcellus-Regular.ttf             - SIL Open Font License 1.1 (Fonts_OFL-1.1.txt)

All other textures were created for this project.

Fray does not ship any Blizzard Entertainment art. Where it uses Blizzard's interface graphics (atlases such as the
unit frame, the casting bar or the dialog frame) it only refers to them by name; they are loaded from the game client.
